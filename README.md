# Kyle — Workforce Planning & Reporting Portfolio

Static portfolio with light/dark mode, two visual styles, interactive demos, and a process improvement case study. No build tools or dependencies are required.

## Publish using GitHub Pages

1. Sign in to GitHub and create a PUBLIC repository named YOURUSERNAME.github.io (replace YOURUSERNAME with your actual GitHub username).
2. Extract this ZIP on your computer.
3. In the repository, choose Add file > Upload files.
4. Upload index.html and README.md from the extracted folder directly into the repository root. Do not upload the ZIP or the containing folder. Include .nojekyll if visible; it is optional for this self-contained site.
5. Commit the files to the main branch.
6. Open Settings > Pages.
7. Under Build and deployment, choose Deploy from a branch.
8. Select main and /(root), then Save.
9. When deployment finishes, visit https://YOURUSERNAME.github.io/. Publication may take up to 10 minutes.

If that user-site repository already exists, use a repository named portfolio instead. The address will be https://YOURUSERNAME.github.io/portfolio/; the same files work at either address.

## Update later

Replace index.html in the repository and commit the change. GitHub Pages republishes automatically. No installation, server, or API keys are needed.

## Content

All demonstration datasets are fictional. Original workbooks, VBA binaries, client information, source paths, hosting credentials, and Sites configuration are excluded. The contact email and employer names are intentionally included as approved by Kyle. Reported workflow timings are distinguished from simulated demo results.
